Post-MVP extraction follows ADR 0064 and does not begin merely because a domain noun exists. First extract a stable public protocol with versioned schemas and conformance fixtures. Then deploy a private opaque encrypted-pack relay that never receives Vault keys or plaintext. Start out-of-process integrations only after the protocol and capability contracts are stable. Evaluate vector retrieval last and ship it only when it materially beats the deterministic Memory baseline without forbidden or stale interventions. Every stage requires its own consumer, owner, entry evidence, exit evidence, rollback, and stop condition before a new repository or service is created. OS sandboxing remains a separate native security gate rather than an excuse to start these extractions early.
