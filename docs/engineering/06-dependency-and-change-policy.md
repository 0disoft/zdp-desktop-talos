# Dependency and Change Policy

Dependencies are pinned through the selected language lockfiles. New packages require ownership, maintenance, license, transitive-code-execution, binary-download, telemetry, vulnerability, and removal review. Automatic package installation by the agent is forbidden in MVP.

MIT, BSD, ISC, and Apache-2.0 are normally acceptable with notices. Copyleft, source-available, commercial SDK, model-weight, font, icon, and bundled-tool licenses require explicit review. Release artifacts include third-party notices and SBOMs. Wails and provider SDKs remain behind replaceable boundaries; `latest` is not a durable version policy.
