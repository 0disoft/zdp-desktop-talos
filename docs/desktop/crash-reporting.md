# Crash Reporting

- Status: Local diagnostics baseline

Remote crash reporting and telemetry are off by default. Local diagnostics retain bounded structured events for a short configured period and exclude prompt bodies, repository source, terminal output, model payloads, credentials, tokens, personal email, and raw memory statements by default.

An explicit export preview shows included categories, byte size, redaction findings, destination, and retention terms before any diagnostic bundle leaves the device. A crash cannot convert an unknown worker attempt into success; restart recovery reconciles the attempt journal, worker identity, and current repository state.
