# Service Levels

- Status: No external SLA before Beta

Internal quality indicators are crash-free task review, recovery without duplicate side effects, Vault-open latency, event-append latency, worker cancellation time, verification freshness, memory intervention quality, and zero secret export. Provider latency and ZDP account availability are reported separately from local Talos availability.

No public availability or recovery-time promise is made until reference platforms, support channels, backup/recovery behavior, and incident ownership are operationally proven.
