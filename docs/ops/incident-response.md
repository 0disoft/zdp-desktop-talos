# Incident Response

Priority incidents include secret export, unauthorized egress, update-signature failure, Vault decryption failure, primary-worktree escape, stale-evidence completion, permission bypass, corrupt migration, and compromised device identity.

Response records bounded non-secret evidence, disables the affected capability or channel, preserves recoverable local state, rotates/revokes relevant credentials or devices, scans projections and remotes, communicates deletion limits honestly, ships a verified repair, and adds a regression fixture. Raw customer repositories or prompts are not collected merely to make diagnosis easier.
